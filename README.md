## What's Inside

- **Experience** — NextGen Federal Systems (MCP services, NOAA GOES pipeline, RAG architecture) and UW Research Assistant work

- **Skills** — Full technical stack from programming languages through visualization tools

## Tech Stack

- **HTML5** · semantic, accessible markup
- **CSS3** · custom design system, responsive grid, light theme with pastel category colors
- **Vanilla JavaScript** · typed headline, scroll reveals, project filters, active nav tracking
- **Google Fonts** · Inter + Fira Code

No build step, no framework — just open `index.html`.

## Run Locally

```bash
git clone https://github.com/kevinabui/portfolio.git
cd portfolio
open index.html          # macOS
# or
python3 -m http.server   # then visit http://localhost:8000
```
